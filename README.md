# EpicQuest

EpicQuest is a Minecraft plugin designed to enhance player progression, quests, storylines, biomes, and bosses. It aims to provide a more immersive and engaging experience by adding depth to the game world and player interactions. This plugin is perfect for server administrators looking to add more content and variety to their Minecraft experience.

## Install

1. Download the plugin JAR file from the [GitHub releases page](https://github.com/yourusername/EpicQuest/releases).
2. Place the JAR file in the `plugins` folder of your Minecraft server.
3. Start or restart your Minecraft server to load the plugin.

## Use

1. Ensure the plugin is installed and the server is running.
2. Players can start interacting with the new quests and storylines by exploring the enhanced biomes and engaging with NPCs.
3. Use the `/quests` command to view available quests and progress.
4. Defeat the new bosses to unlock additional rewards and progress further in the storyline.
